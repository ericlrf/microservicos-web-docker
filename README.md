# Microsserviços em Aplicações WEB com Docker

Demonstração prática de arquitetura de microsserviços utilizando Node.js e Docker Compose.

> **Curso:** Técnico em Desenvolvimento de Sistemas  
> **Tempo de execução:** ~5 minutos para levantar toda a infraestrutura

---

## 🎯 Objetivo

Esta demonstração ilustra como construir uma aplicação web composta por microsserviços independentes, cada um em seu próprio container Docker, comunicando-se através de uma rede privada virtual.
